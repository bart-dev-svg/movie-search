# Movie Search

A React app that searches movies using the OMDb API and shows results as a grid of poster cards.

**Live site:** https://your-link-here.vercel.app

## Features
- Search any movie by title
- Loading and error messages
- Responsive poster grid

## Built with
- React (Vite)
- OMDb API
- CSS Grid

## Run it locally
1. Clone the repo and run `npm install`
2. Get a free key at omdbapi.com
3. Create a `.env.local` file containing `VITE_OMDB_KEY=your_key`
4. Run `npm run dev`
